# Sakinah Portfolio
Static single-file HTML website. Open index.html in a browser.

## Deploy to Vercel
Create a new GitHub repository, upload index.html, then import the repository into Vercel as a new project. Select Other as the framework preset; no build command or dependencies are required. Confirm the preview before replacing the existing site.

Content and images are sourced from the provided portfolio PDF. The LinkedIn URL was provided by the portfolio owner. Verify work metrics, dates, and certificate visibility before publishing.
